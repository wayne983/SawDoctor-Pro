鋸片醫生管理系統 v8.7 — 安裝說明
===================================

【v8.7 新增功能】
  ✓ 派工清單支援「跨 2 個月」範圍選擇,處理跨月份還在維修的鋸片
    - 單一月份(預設)
    - 跨 2 個月 (本月 + 上個月)
    - 跨 2 個月 (本月 + 下個月)
    - 自訂兩個月

【v8.6 功能】
  ✓ 派工清單已自動排除「報廢」鋸片
  ✓ 派工清單可匯出 Excel (.xlsx) / Word (.docx) / HTML 三種格式
  ✓ 儀表板新增「📤 匯出 Excel」按鈕,一鍵輸出 5 個工作表的完整總覽
  ✓ 派工清單可選「未完成 / 研磨中 / OK回來 / 已出貨 / 全部」
  ✓ 派工清單可選「是否包含已報廢的鋸片」
  ✓ 廠商回傳 JSON 對帳檔,系統會自動更新狀態到資料庫並同步到儀表板

【匯出 Excel/Word 套件需求】
  第一次使用匯出功能前,請執行一次:
  pip install -r requirements.txt
  或者:
  pip install openpyxl python-docx python-pptx pillow

【基本安裝 (3步)】

步驟 1. 確認 Python 已安裝
  - 已確認您有 Python 3.13.7,可直接進行

步驟 2. 安裝 Python 套件 (一次就夠)
  - 開「命令提示字元」執行:
    pip install -r requirements.txt
  - 包含: python-pptx, Pillow (PPT用), openpyxl, python-docx (匯出用)

步驟 3. 雙擊啟動
  - 雙擊「鋸片醫生.bat」即可開啟管理視窗
  - 或直接對「鋸片醫生.py」右鍵 → 用 Python 執行

【首次使用】
  1. 開啟後會自動掃描 NAS
  2. 如果 NAS 路徑不對,點上方「⚙ 設定」修改
  3. 掃描完成後,所有分頁自動顯示資料

【視窗功能】
  📊 儀表板    KPI、月份分布圖、客戶排行、逾期清單
              右上角「📤 匯出 Excel」一鍵輸出總覽報表
  📅 依月份    選左側月份 → 看該月所有鋸片狀態
  👥 依客戶    可搜尋客戶名,看所有鋸片進度
  📋 派工清單  可選輸出格式 (HTML/Excel/Word) 和篩選條件
  📥 匯入對帳檔 廠商回傳 .json 後,自動更新狀態到資料庫
  雙擊任一列  可開啟資料夾、產生補齒PPT、標記已出貨

【派工清單匯出格式說明】
  HTML  - 適合在電腦上打開、勾選後產生回傳檔給系統
  Excel - 廠商收到後可直接列印 / 修改 / 加備註
  Word  - A4 直式精美格式,廠商可手寫勾選後簽收

【客戶維修報價明細（未稅）】
  1. 在「派工清單」選擇月份範圍與狀態。
  2. 輸出格式選「客戶維修報價明細 Excel」，再選擇一位客戶。
  3. 在逐片確認畫面決定是否列入本次清單；可人工調整研磨、補齒、反板校正的數量、單價與備註。
  4. 確認每列小計及底部「未稅總計」後，按「產生客戶維修報價明細 Excel」。
  5. 系統只會輸出該客戶的逐片明細；每片保留獨立編號，並依規格分段顯示。

  自 2026-08-13 起的自動未稅價：
  - 外徑 305：研磨 240 元／片、補齒 150 元／齒、反板校正 230 元／片。
  - 外徑 355：研磨 280 元／片、補齒 150 元／齒、反板校正 230 元／片。
  - 外徑 405–455：研磨 350 元／片、補齒 150 元／齒、反板校正 250 元／片。
  - 補座、鋼面、報廢與特殊處理不會自動計價；請由技師填寫人工確認說明，或將該片排除本次清單。

  報價保存與檔案：
  - 每次輸出會保留當次單價、數量、小計與價目版本快照；之後調價不會改變既有明細。
  - Excel 輸出到程式資料夾下的「客戶維修報價」資料夾，檔名包含客戶、月份範圍與報價單號。
  - 同名檔案不會覆蓋；請重新建立新的報價批次後再輸出。
  - 第一次啟動時，系統會在既有 sawblade.db 自動建立報價相關資料表，不會覆寫既有資料庫或工單資料。
  - 此功能供人工行政報價確認使用，不是 AI 自動診斷或維修判定。

【儀表板 Excel 工作表】
  Sheet 1: 總覽 KPI       7 項關鍵指標
  Sheet 2: 月份分布        各月研磨中/OK回來/已出貨/報廢明細
  Sheet 3: 客戶排行        本月起依件數排行
  Sheet 4: 逾期將到期      近 7 天內到期 + 已逾期
  Sheet 5: 全部明細        每片鋸片完整記錄

【顏色說明】
  白色 = 研磨中(送出後約 10-12 工作天回來)
  藍底 = OK 回來/待出貨
  綠底 = 已出貨
  紅底 = 逾期
  灰底 = 報廢

【資料檔案位置】
  sawblade.db    資料庫 (自動建立)

  派工清單_*.xlsx   匯出的 Excel
  派工清單_*.docx   匯出的 Word

【時間規則】
  - 系統從 2026/4 月正式啟用
  - 2026/3 月以前的資料自動標記為「已出貨」
  - 進貨日 = 工單資料夾建立時間
  - 最早交期 = 進貨日 + 10 工作天
  - 最晚交期 = 進貨日 + 12 工作天

如有問題,請查看 crash.log 或 scan_debug.log
