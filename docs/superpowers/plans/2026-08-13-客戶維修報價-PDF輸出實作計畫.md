# 客戶維修報價 PDF 輸出實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓客戶維修報價確認畫面可選擇輸出 Excel、PDF 或兩者，並維持同一份報價快照與原子性。

**Architecture:** 在既有 `save_and_export_customer_quote()` 上擴充多格式輸出協調器；它先確認所有檔名無碰撞，再於同一 SQLite 交易中保存快照、建立所選檔案、寫入輸出紀錄，全部成功才提交。PDF 匯出器只讀取已確認的 `QuoteLineDraft`，與 Excel 共用欄位及小計資料，並以 ReportLab 輸出 A4 直式多頁表格。

**Tech Stack:** Python 3、Tkinter、SQLite、openpyxl、ReportLab、pypdf/pdfplumber、Poppler `pdftoppm`。

## Global Constraints

- 只修改 `work/鋸片醫生管理系統_v8.8`；不可變更原 v8.7、使用者現有 `sawblade.db`、已產生 HTML/Excel 或 log。
- 所有文字為繁體中文；報價為未稅；不同客戶不得混入同一批次。
- PDF 與 Excel 必須使用同一批確認列；不可重新依價目表推算，亦不可回寫原始工單。
- PDF 使用 Windows 已存在的 `C:\Windows\Fonts\msjh.ttc`（必要時以 `mingliu.ttc` 作可讀繁中後備），不得將系統字型拷入發佈包。
- 既有 `quote_batches.output_file` 保持可讀：有 Excel 時存 `.xlsx`，僅 PDF 時存 `.pdf`；新表保存每一份實際輸出。
- 任一輸出或提交失敗，回滾資料庫並只移除本次新建的檔案；不得覆蓋或刪除碰撞的既有檔案。
- 測試不得在 v8.8 發佈目錄留下 `.pdf`、`.xlsx`、`__pycache__`、WAL/SHM 或 log。
