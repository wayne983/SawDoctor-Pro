# 客戶維修報價明細 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 將既有派工清單擴充為可選單一客戶、逐片人工確認金額並輸出未稅維修報價明細 Excel 的功能。

**Architecture:** 原始 v8.7 安裝包保留不動；先在工作區建立 v8.8 工作副本。以獨立 `quote_domain.py` 封裝價目版本、報價草稿及金額計算，主程式只負責 SQLite 遷移、Tkinter 報價確認畫面與 Excel 輸出。每次輸出將單價與明細快照寫入 SQLite，確保後續調價不變更既有客戶清單。

**Tech Stack:** Python 3.13、Tkinter、SQLite、openpyxl、unittest。

## Global Constraints

- 原始 `C:\Users\user\Downloads\01_鋸片醫生\鋸片醫生_安裝包_v8.7` 僅供讀取；所有修改在工作區 v8.8 副本進行。
- 介面、輸出、文件使用繁體中文與 UTF-8 無 BOM。
- 只支援研磨、補齒、反板校正三種自動計價；補座、鋼面、報廢與特殊處理不得自動計價。
- 價格均為未稅新台幣；不加入營業稅、折扣、付款條件或自動寄送。
- 自 2026-08-13 起的價目：305 為研磨 240／補齒 150 每齒／反板 230；355 為 280／150／230；405–455 為 350／150／250。
- 未支援外徑或任一必須收費項目缺少人工價格時禁止輸出，不得猜測價格。
- 一份清單只屬於一位客戶；每片工單獨立一列與獨立編號，即使規格、維修項目相同也不可合併金額。
- 報價確認不得回寫 `blades` 的損傷、工序或狀態欄位。
- 已輸出的報價批次與明細快照不可覆蓋；日後調價只新增版本。

```python
class PriceRule:

def build_quote_line(blade, rule):
    teeth = parse_nonnegative_int(blade["supp_teeth"])
    grinding_qty = 1 if blade["grind"] == "是" else 0
    fanban_qty = 1 if blade["fanban"] == "是" else 0
    return QuoteLineDraft(..., grinding_qty=grinding_qty, tooth_qty=teeth, fanban_qty=fanban_qty,
        grinding_unit=rule.grinding_price if grinding_qty else 0,
        tooth_unit=rule.tooth_price if teeth else 0,
        fanban_unit=rule.fanban_price if fanban_qty else 0)
```

```sql
  id TEXT PRIMARY KEY, effective_from TEXT NOT NULL UNIQUE, created_at TEXT NOT NULL

CREATE TABLE IF NOT EXISTS price_rules(
  version_id TEXT NOT NULL, od_min INTEGER NOT NULL, od_max INTEGER NOT NULL,
  grinding_price INTEGER NOT NULL, tooth_price INTEGER NOT NULL, fanban_price INTEGER NOT NULL,
  PRIMARY KEY(version_id, od_min, od_max)
);
CREATE TABLE IF NOT EXISTS quote_batches(
  id TEXT PRIMARY KEY, customer TEXT NOT NULL, month_range TEXT NOT NULL,
  created_at TEXT NOT NULL, created_by TEXT NOT NULL, price_version_id TEXT NOT NULL,

CREATE TABLE IF NOT EXISTS quote_lines(
  id INTEGER PRIMARY KEY AUTOINCREMENT, batch_id TEXT NOT NULL, blade_id INTEGER NOT NULL,
  display_order INTEGER NOT NULL, spec TEXT NOT NULL, brand_id TEXT NOT NULL,

  tooth_qty INTEGER NOT NULL, tooth_unit INTEGER NOT NULL,
  fanban_qty INTEGER NOT NULL, fanban_unit INTEGER NOT NULL,
  subtotal INTEGER NOT NULL, note TEXT NOT NULL
);
```
