# 派工清單精簡版面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 將 Excel、HTML、Word 派工清單統一為含獨立數量欄、純研磨合併、短日期與無備註區的 14 點字體版面。

**Architecture:** 以 `_group_for_export(rows)` 作為唯一的純函式分組來源，讓 HTML、Excel、Word 都讀取同一份派工列資料。純研磨以客戶與規格合併；任一附加工序的鋸片以輸入順序個別保留，避免不同鋸片被錯誤合併。三個轉出器只處理各自格式的欄位、字體、列印與簽收版面。

**Tech Stack:** Python 3、Tkinter 既有程式、SQLite row、openpyxl、python-docx、unittest。

## Global Constraints

- 所有輸出與文件使用繁體中文及 UTF-8 無 BOM。
- 僅修改 `work/鋸片醫生管理系統_v8.8`，不得修改 v8.7 原始程式、SQLite 原始資料或既有報價功能。
- 共用欄位固定為「勾選、項次、客戶、數量、編號、規格、補齒、補座、反板、鋼面、進貨日／交期」。
- 只有補齒、補座、反板、鋼面都沒有資料的同客戶、同規格鋸片可以合併；其餘逐片列出且數量為 1。
- 合併列的代表編號採輸入順序第一支；日期採最早進貨日與最晚交期，顯示為 `MM/DD-MM/DD`。
- 表格表頭與內容均為 14 點字體；移除右側備註欄與所有底部備註區，保留簽收／覆核與 A4 列印設定。
