# 派工清單彙總版面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓 HTML、Excel 與 Word 派工清單以同客戶同規格彙總，且不顯示編號。

**Architecture:** 保留 `_group_for_export(rows)` 作為三種輸出的唯一資料整理入口。它將每片鋸片轉成標準化資料後，依客戶和規格合併，產生短日期、數量與維修項目彙總；各匯出器只負責呈現固定的九欄資料。

**Tech Stack:** Python 3、unittest、openpyxl、python-docx、現有 HTML 產生器。

## Global Constraints

- 使用繁體中文；規格採半形斜線且不含空白，例如 `305/3.0T/100T`。
- 三種派工輸出皆為直式 A4，內文以 14 點字為基準。
- 固定欄位順序為 `勾選｜項次｜進貨日｜客戶｜規格｜數量｜維修項目｜備註｜交期`。
- 不輸出鋸片編號；不回寫資料庫或改變既有資料夾與報價功能。
- 僅修改明確列出的原始碼、測試與文件；不提交資料庫、暫存檔、使用者匯出檔或 `vendor/`。
