# 客戶維修報價 PDF 輸出設計

日期：2026-08-13  
狀態：已實作；待於具備桌面環境時進行人工 GUI 視覺驗收

## 目標

在既有的「客戶維修報價確認」畫面，讓技師在確認每片維修金額後，自行選擇輸出 Excel、PDF，或同時輸出兩者。所有格式必須使用同一份已確認的報價快照，避免客戶收到的 PDF 與 Excel 金額不同。

## 操作流程

```text
派工清單 → 選月份、狀態、單一客戶 → 客戶維修報價明細 Excel
→ 逐片確認／人工填價 → 選輸出格式
→ Excel／PDF／Excel＋PDF → 建立報價快照與輸出檔案
```

報價確認視窗在「未稅總計」旁新增唯讀選項：

- `Excel（.xlsx）`：輸出可編輯的客戶維修報價明細。
- `PDF（A4）`：輸出適合列印或傳給客戶的固定版面。
- `Excel＋PDF`：從相同批次、相同逐片價格同時輸出兩個檔案。

預設選項為 `Excel（.xlsx）`，以維持現有操作習慣。

確認後會把選項轉為 `("xlsx",)`、`("pdf",)` 或 `("xlsx", "pdf")`，交由同一個原子化報價協調器處理。成功時，Excel 選項開啟 Excel、PDF 選項開啟 PDF、雙檔選項開啟 PDF，並在日誌列出兩個檔名。

## PDF 格式

- A4 直式，使用可嵌入的繁體中文字型。
- 第一頁包含「鋸片醫生 HAWER SAWDOCTOR」、客戶名稱、報價單號、產生日期與「未稅」標示。
- 表格欄位與 Excel 一致：項次、規格、研磨、補齒、補座、反板校正、小計 NT$、備註。
- 每片鋸片獨立一列；相同規格連續分段，但不合併金額。
- 表格過長時自動換頁，後續頁重複欄位標題；最後一頁顯示「未稅總計」。
- 補座、鋼面、報廢、特殊處理不自動計價；人工確認內容保留於備註。

## 資料與原子性

- 報價批次仍只允許一位客戶，且只保存已列入的逐片項目。
- Excel 與 PDF 都從同一批 `QuoteLineDraft` 確認值建立；不得重新依目前價目表計價。
- 批次新增 `quote_output_files` 輸出檔案紀錄，一個批次可有 `xlsx` 與／或 `pdf`。既有 `quote_batches.output_file` 保留作為第一個產出的相容欄位。
- 所有選定檔案成功建立後才提交報價快照；任一輸出、寫檔或提交失敗時，回滾資料庫並只刪除本次新建的檔案。不得刪除既有同名檔案。
- 同名檔案受保護，不覆蓋。輸出檔名共用同一報價單號，副檔名分別為 `.xlsx` 與 `.pdf`。

## 開啟與提示

- 成功時開啟使用者選擇的主要檔案：選 Excel 開 Excel，選 PDF 開 PDF，選兩者時開 PDF，Excel 同時保存在同一輸出資料夾。
- 日誌列出所有成功輸出的檔名。
- 若 PDF 依賴或中文字型不可用，顯示清楚錯誤，不建立任何報價批次或不完整輸出。

## 不包含範圍

- 不修改原始工單、維修判定或歷史報價。
- 不自動寄送 Email／LINE，不加入稅額、付款條件、折扣或正式合約條款。
- 不輸出不同客戶合併檔案。

## 安裝與使用邊界

- PDF 使用既有 `ReportLab` 與 `pypdf` 相依套件；不另採用第二套 PDF 引擎。
- PDF 為 A4 固定版面，供列印或傳送給客戶；Excel 保持可編輯，供行政人員後續處理。
- 系統不會自動寄送 Email 或 LINE。輸出後的列印、傳送與客戶確認，仍由人員執行。

## 驗收條件

1. 使用者能在確認畫面選 Excel、PDF、Excel＋PDF。
2. PDF 各列與 Excel 的規格、數量、單價、小計、備註與未稅總計完全一致。
3. 多頁 PDF 每頁有欄位標題，繁中內容可閱讀，沒有欄位截斷或重疊。
4. 選 PDF 時只建立 PDF；選 Excel 時維持既有 Excel 行為；選兩者時建立同報價單號的兩份檔案。
5. 任一輸出失敗時，資料庫沒有新批次、沒有新列，且不留下本次不完整檔案。
6. `quote_output_files` 能查到新批次每個輸出格式與檔名；舊批次資料可讀取。
