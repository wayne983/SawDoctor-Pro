# 派工清單彙總版面設計

## 目的

將提供給研磨廠商的派工清單精簡為直式 A4 的彙總表。廠商只需要看到規格、數量、待處理的維修項目、可手寫的備註與交期；鋸片編號不顯示。

## 適用範圍

同一份派工清單的 HTML 預覽、Excel 匯出與 Word 匯出必須採用相同資料彙總與欄位順序。既有資料庫、鋸片資料夾名稱與客戶維修報價功能不變。

## 彙總規則

1. 以「客戶名稱 + 完整規格」作為一列彙總的鍵值；完整規格包含外徑、厚度與齒數。
2. 同鍵值的每一片鋸片合併為一列，數量為合併後的鋸片數。
3. 不論只有研磨或另有補齒、補座、反板、鋼面，均依上述規則彙總；不再因額外維修項目拆成個別列。
4. 維修項目欄只顯示額外維修的合計：補齒加總實際齒數、補座加總實際座數，反板與鋼面各計算標示「是」的片數。格式為 `補齒x5、補座x3、反板x2、鋼面x1`，數量為零的項目不顯示。
5. 研磨是基礎流程，不在維修項目欄重複列出；沒有額外維修時該欄保持空白，不使用橫線或其他符號。
6. 因為清單不顯示編號，彙總資料仍保留原始鋸片資料夾路徑供系統勾選、完成狀態與內部流程使用，但不輸出給廠商。

## 欄位與格式

欄位固定順序如下：

`勾選｜項次｜進貨日｜客戶｜規格｜數量｜維修項目｜備註｜交期`

- 進貨日及交期各自顯示為 `MM/DD`，例如 `08/13` 與 `08/26`。
- 規格使用半形斜線、無空白的格式，例如 `305/3.0T/100T`，並維持單行；必要時縮小該格文字，不主動把規格分行。
- 備註是完全留白的欄位，供廠商手寫；不帶入原始資料，也不回寫系統。
- 不顯示編號欄、既有的個別補齒／補座／反板／鋼面欄，或舊版「進貨日／交期」合併欄。
- 表格以直式 A4、14 點字為基準，充分使用可用寬度；只有實際列數超出紙面時才續頁。

## 各輸出格式

- HTML：標題列、廠商／交貨日／收件人欄位與彙總表保持既有功能；新增欄位以固定欄寬呈現，規格、日期與數量不換行。
- Excel：標題列後輸出九欄，維修項目可依內容自然顯示，備註欄保持空白並提供可書寫寬度。
- Word：標題列後輸出九欄，以直式 A4 列印；規格、日期與數量優先單行，備註欄保持空白。

## 驗收與測試

自動測試必須驗證：

1. 同客戶、同規格的鋸片會合併，且數量正確。
2. 不同客戶即使規格相同也不合併。
3. 額外維修數量可正確彙總，且無額外維修時維修項目為空字串。
4. HTML、Excel 與 Word 的欄位順序皆為九欄，沒有「編號」欄。
5. 日期為短日期、規格使用半形斜線、備註欄存在且為空白。
