# HAWER 官網關鍵字導覽助手設計規格

## 目的與範圍

在 `https://www.hawer-knife.com/` 的每一頁右下角提供「AI 提問」浮動按鈕。訪客以繁體中文輸入關鍵字或簡短問題後，系統顯示保守的導引句與最多三個相關站內頁面。第一版是可人工維護的關鍵字導覽，不呼叫生成式 AI、資料庫或第三方服務。

此功能的成功標準為：訪客能用產品、材料、服務或切割困擾的文字，快速開啟現有網站中最相關的頁面；管理者可只修改一份頁面索引來新增或修正導覽。

## 不在範圍內

- 不蒐集、儲存或傳送訪客提問內容。
- 不使用 API 金鑰、外部聊天模型或分析追蹤服務。
- 不新增、取代或刪除既有的產品、FAQ、詢價或聯絡頁面。
- 不進行技術確診、推薦保證有效的鋸片規格，或取代真人技師。

## 使用者介面

### 觸發與對話框

- 右下角顯示圓形按鈕，文字為「AI 提問」。
- 點擊後開啟可關閉的對話框，包含標題、簡短使用說明、輸入欄、送出按鈕、常用捷徑與結果區。
- 按下 Enter 與點擊送出都會查詢；Esc 關閉對話框；關閉後焦點回到浮動按鈕。
- 行動裝置上對話框保留視窗邊界與可捲動結果區，不遮住輸入與關閉按鈕。

### 結果呈現

- 先顯示一則不含未證實技術結論的導引句。
- 顯示最多三張結果卡：頁面名稱、簡短說明與「前往查看」連結。
- 空白輸入提示使用者輸入材料、產品、服務或困擾，例如「鋁棒」、「研磨」或「切面毛邊」。
- 無匹配時清楚告知尚無對應頁面，提供現有的「線上詢價」與「聯絡我們」導向。

## 頁面索引與比對

程式內有一份獨立的 `PAGE_INDEX` 陣列。每個項目具備：

- `id`：穩定識別碼。
- `title`：顯示名稱。
- `url`：官網既有絕對網址。
- `summary`：結果卡片的簡短說明。
- `keywords`：可維護的繁體中文、英文、規格與同義字清單。
- `priority`：同分時的排序依據。

初始索引至少涵蓋：

1. HAWER 鋸片醫學誌：切削困擾、毛邊、塞鋁屑、端跳、轉速、法蘭盤、切削油與齒鈍等教育內容。
2. 鋸片研磨與維修：研磨、修磨、鈍齒、齒面、顯微檢查與售後服務。
3. 鋸片診療系統：健檢、診療、顧問、ISO、檢查與真人確認。
4. 鋁用大外徑產品：鋁棒、鋁胚、鋁錠、鋁擠型、非鐵金屬與 650 至 1870 mm。
5. 鋁合金產品：鋁管、鋁板、鋁棒、鋁擠型、銅件與 355 至 610 mm。
6. 型鋼冷切與熱切產品：型鋼、鋼鐵、冷切、熱切與 2100 至 2200 mm。
7. 木工與塑料產品：木工、木材、壓克力、塑料與 255 至 455 mm。
8. WIKUS 金屬鋸帶、FAQ、線上詢價與聯絡我們。

查詢會依序做以下正規化：去除前後空白、轉為小寫、統一常見全半形符號，並將輸入依空白與標點切成詞。每個匹配關鍵字累加分數；完整片語命中加權較高；最後以優先級與索引順序穩定排序。結果不超過三筆。

## 安全導流規則

若提問含有下列任一警示詞：`裂紋`、`裂痕`、`缺齒`、`掉齒`、`變形`、`劇烈震動`、`異常震動`、`冒煙`、`火花`，結果區最上方固定顯示：

> 出現可能影響安全的異常時，請先停機檢查；本頁僅供初步導引，請由真人技師確認。

警示詞會讓「鋸片診療系統」與「聯絡我們／線上詢價」置頂；仍不顯示原因判定、維修處方或性能保證。

## 安裝與維護

- 將單一自包含程式碼片段放入官網後台的全站頁尾自訂 HTML／程式碼區，以便在所有公開頁面載入一次。
- 元件的樣式以專屬 `hawer-ai-` 前綴隔離，避免影響既有網頁樣式。
- 連結一律使用 HTTPS 絕對網址；新視窗連結加上 `rel="noopener"`。
- 日後只需在 `PAGE_INDEX` 中新增或調整項目，不必修改搜尋核心。

## 錯誤處理與可近用性

- 程式初始化失敗時不干擾既有網站，僅不顯示元件。
- URL 缺失的索引項目不列入結果。
- 以可見標籤、`aria-expanded`、`aria-controls` 與焦點管理支援鍵盤操作。
- 不以顏色作為唯一提示，按鈕與結果卡維持足夠文字對比。

## 驗證策略

先建立可在瀏覽器外執行的純 JavaScript 搜尋核心與測試，確認測試先因功能不存在而失敗；再實作最小程式使其通過。至少覆蓋：

1. 「鋁棒切割」回傳鋁用大外徑產品。
2. 「鋸片研磨」回傳研磨維修頁面。
3. 「切面毛邊」回傳鋸片醫學誌。
4. 「裂紋與劇烈震動」啟用停機提示，並讓診療導流置頂。
5. 空白與無結果輸入有明確、安全的回應。
6. 結果最多三筆且排序可預期。
7. HTML 片段靜態檢查，確認只有一個元件根節點、無外部腳本與所有索引 URL 為 HTTPS。

完成後會用桌面與窄螢幕尺寸進行實機操作檢查，並在實際官網後台發布前由使用者貼上或授權可見後台操作。
