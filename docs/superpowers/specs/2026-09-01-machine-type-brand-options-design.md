# 鋸片診療系統：機台種類與品牌選單設計

## 目標

將設備資料改成「機台種類 → 對應品牌 → 設備型號」的兩層選擇。三個欄位都不是掛號必填欄位；客戶留空仍可查看初步診斷及送出掛號。

## 選項

- 木工圓鋸機：邰展、勝源、SAWSTOP、萬代利、博銓、嘉元全、麗達、慶祥、其它。
- 鋁用：日意、鋒和、冠盛、和和、慶祥、合濟、中勝、昱帆、其它。
- 鐵工：慶祥、合濟、捷順、鋼鐵宿敵、其它。
- 電動木工：博世、牧田、力山、FESTOOL、HIKOKI、其它。

「其它」在介面顯示為「其它」，資料值沿用既有的 `其他`，以維持其他品牌欄位、Email 與舊掛號資料的相容性。

## 互動

1. `machineType` 空白時，品牌選單停用並顯示「請先選擇機台種類」。
2. 選擇機台種類後，`machineBrand` 只顯示該種類的品牌。
3. 更換機台種類時，清除舊品牌及其他品牌文字，避免跨類別殘留。
4. 選擇「其它」時顯示 `machineBrandOther`；離開「其它」時隱藏並清空。
5. `machineModel` 維持自由文字欄位。
6. 所有欄位皆可留空，不新增前端或後端必填驗證。

## 資料流

- 初步診斷及 LINE 摘要新增「機台種類」，並保留設備品牌與設備型號。
- Email 初診單新增「機台種類」。
- 掛號試算表在現有最後一欄後追加「機台種類」，不搬動歷史欄位。
- 已填種類、品牌或型號時不得再次要求同一資料；未填時可列入「請追加補充」，但不阻擋診斷或掛號。
- 不依機台種類或品牌推測 RPM、鋸片外徑、切幅、齒數或切割能力。

## 完成條件

- 四種機台的品牌名單完全符合核准內容。
- 切換種類不會保留不相容品牌。
- 其他品牌欄位只在選擇「其它」時存在於送出資料。
- LINE、Email、試算表皆保存機台種類。
- 現有安全判定、掛號編號、雙信箱寄送與官方 LINE 流程不受影響。
