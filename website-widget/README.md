# HAWER 官網關鍵字導覽助手

這個資料夾提供一份可直接貼入 HAWER 官網後台的右下角關鍵字導覽元件。它不會呼叫外部 AI、儲存訪客提問或改寫既有頁面；訪客輸入關鍵字後，只會得到既有官網頁面的相關連結。

## 檔案

- `hawer-keyword-navigator.embed.html`：唯一需要貼入網站後台的完整程式碼。
- `tests/hawer-keyword-navigator.test.js`：交付前的自動測試。

## 後台安裝

1. 先在網站後台複製並備份現有的「全站頁尾自訂 HTML／程式碼」內容。
2. 開啟 `hawer-keyword-navigator.embed.html`，完整複製內容。
3. 在後台的**全站**頁尾自訂 HTML／程式碼區貼上一次，然後儲存並發布。
4. 不要在每一個頁面各貼一次；若同一段程式重複載入，會產生多個按鈕。
5. 若後台沒有全站插入區，先停止發布，請網站維護商提供可套用到全站的頁尾程式碼區；不要以逐頁重複貼上代替。

## 發布前驗證

在本資料夾的上一層專案根目錄執行：

```powershell
node --test website-widget/tests/hawer-keyword-navigator.test.js
git diff --check -- website-widget
```

預期結果是所有測試通過，且格式檢查沒有輸出。

## 發布後驗證

在實際官網的首頁、任一產品頁與鋸片醫學誌頁面，各以桌面版及 390px 寬度的手機版檢查：

1. 右下角只出現一個「AI 提問」按鈕，點擊能開啟與關閉對話框。
2. 輸入後按 Enter 與按「查詢」都能得到結果；按 Esc 關閉後焦點回到「AI 提問」按鈕。
3. 依序查詢 `鋁棒切割`、`鋸片研磨`、`切面毛邊`，確認前三筆連結導向合理的既有頁面。
4. 查詢 `裂紋 劇烈震動`，確認最上方提示「先停機檢查」與「真人技師確認」，且不顯示確診、處方或保證改善。
5. 查詢無對應文字，確認顯示安全說明；若頁面導覽列含線上詢價或聯絡我們連結，應出現「聯絡我們協助確認」卡片。
6. 手機版面板不得超出螢幕，輸入欄、關閉按鈕與結果卡都必須可操作。

若上述任一項不符合，先將後台貼上的片段移除或還原備份，保留問題畫面與輸入文字後再調整。

## 維護頁面索引

所有可維護資料都在 `hawer-keyword-navigator.embed.html` 的 `PAGE_INDEX` 陣列。新增或調整導覽時，僅修改各項目的：

- `title`：結果顯示的頁面名稱。
- `url`：目前官網的 HTTPS 絕對網址。
- `summary`：不帶性能保證的簡短說明。
- `keywords`：使用者可能輸入的材料、服務、產品、規格或同義詞。
- `priority`：多個結果同分時的顯示優先順序，數字越大越優先。

每次改動 `PAGE_INDEX` 後，重新執行發布前驗證。對 `裂紋`、`缺齒`、`變形`、`劇烈震動`、`冒煙`、`火花` 等警示詞，請維持現有的停機與真人確認導流，不要改成自動判定或保證解法。
