# 鋸片醫生 AI 診療知識庫

## 知識庫用途

本知識庫用於整理鋸片診療所需的症狀、材料、原因、追問、案例、解決方案與 AI Prompt，支援「鋸片醫生」進行初步問診、補充資料、可能原因分析及人工診療前的資訊整理。

本知識庫提供的是技術參考與初步判斷依據，不等同正式選型、加工處方或安全判定。遇到安全警訊、資料不足、未知鋸片類型、特殊材料、金屬／HSS 加工或高風險工況時，應保留停機檢查與人工確認。

## 目錄結構

| 目錄 | 用途 |

| `05_AI追問題庫` | 定義 AI 根據已知資訊應追加詢問的問題 |
| `06_案例資料庫` | 保存已匿名化的診療案例、處理過程與結果 |

| `09_待整理資料` | 暫存尚未查證、分類或審核的網路及現場資料 |

各目錄的收錄範圍與建議欄位，請參閱目錄內的 `README.md`。

## 資料新增原則

1. 所有文件使用台灣繁體中文，編碼統一為 UTF-8。
2. 檔名建議使用 `YYYY-MM-DD_主題_來源.md`；不得覆蓋既有檔案，同名時使用 `v2`、`v3`。
3. 網路資料必須記錄來源機構、原始網址、發布或更新日期（若可取得）及查閱日期。
4. 不整篇複製受著作權保護的文章；以摘要、改寫及必要的短引用保存重點。
5. 新取得且未確認的內容先放入 `09_待整理資料`，完成來源與適用條件審核後再移入正式分類。
6. 明確區分「來源事實」「現場觀察」「推測原因」與「建議處理」，不得把推測寫成確定診斷。
7. RPM、線速度、進給、齒數、齒型、角度及壽命等數值，必須同時記錄適用材料、鋸片、機台與加工條件。
8. 不使用「保證改善」「一定安全」「固定適用」等絕對語句；資料不足時列出缺少項目並轉交人工確認。
9. 案例須移除客戶姓名、電話、地址、報價及其他不必要的識別資訊。
10. 若檔案已存在，先閱讀原內容，再以追加或合併方式更新，並保留原始來源與更新紀錄。

## 建議知識狀態

- `待整理`：已取得資料，但尚未完成分類與來源檢查。
- `待確認`：來源可追溯，但技術內容或適用條件仍需人工審核。
- `已驗證`：已完成來源、條件、安全邊界及人工審核。
- `已停用`：內容過時、被更可靠資料取代或不再適用；保留停用原因，不直接刪除。
